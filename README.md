## Current repository contents

### Fundamentals
- Variables and data types
- Control flow
- Functions
- Core data structures
- Basic exercises and worked solutions

### Intermediate
- Object-oriented programming
- Decorators
- Object-oriented programming exercises

The folders and files listed above reflect the material currently committed to this repository. Advanced Python, web development, data engineering, and deep-learning modules are not currently included.

## Getting started

Clone the repository and work through the Markdown notes in order:

```bash
git clone https://github.com/BoluS095/Python---training---materials.git
cd Python---training---materials
```

Python exercises can be run with Python 3.10 or newer:

```bash
python fundamentals/exercises/basics.py
python intermediate/exercises/oop_exercises.py
```

Solutions are provided for selected exercises. Try each exercise before looking at its solution.
